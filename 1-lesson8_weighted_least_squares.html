權 P 與加權最小二乘

前面我們讓每一筆觀測「一人一票」。但真實測量中，不同觀測的精度可能差很多。這一堂要學會：可信度不同，影響力也應該不同。

① 為什麼不能每筆觀測都一樣重要？

觀測 A
10.000 m
標準差 σ = 0.001 m（±1 mm）
觀測 B
10.010 m
標準差 σ = 0.010 m（±10 mm）

如果直接平均，兩筆資料各佔 50%。但 A 的不確定程度比 B 小很多，所以 A 應該對最後答案有更大的影響。

② 權重的基本公式

pᵢ = 1 / σᵢ²

σ 越小 → σ² 越小 → 1/σ² 越大 → 權 p 越大。

目前先採最常見的「彼此獨立觀測」情況，因此 P 是對角矩陣。

你可以把某一筆 σ 改得很大，例如從 0.002 改成 0.050。它的權會迅速變小，最後的平差值也會越來越不受它影響。

⑥ P 矩陣是什麼？

三筆互相獨立的觀測，其權矩陣寫成：

p₁00 0p₂0 00p₃

對角線放每一筆觀測自己的權；非對角線目前是 0，表示暫時假設不同觀測之間沒有相關性。

⑦ 為什麼 Aᵀv = 0 會變成 AᵀPv = 0？

前面普通最小二乘最小化的是：
S = vᵀv = v₁² + v₂² + v₃²
現在不同觀測的重要性不同，因此把每個殘差平方乘上權：
S = vᵀPv = p₁v₁² + p₂v₂² + p₃v₃²
又因為：
v = L − Ax
所以：
S = (L−Ax)ᵀ P (L−Ax)
對未知數 x 微分，令最小值處的斜率為 0：
AᵀP(L−A x̂) = 0
展開：
AᵀPL − AᵀPA x̂ = 0
移項得到加權法方程：
AᵀPA x̂ = AᵀPL

⑧ 只有一個未知數時，公式其實很簡單

如果三次都是量同一個未知距離 x：

A = [1,1,1]ᵀ

代入加權法方程，最後就是：

x̂ = (p₁L₁ + p₂L₂ + p₃L₃) / (p₁+p₂+p₃)

也就是你剛才互動計算器算出的「加權平均」。所以加權平均其實就是最簡單的一種加權平差。

⑨ 本堂你要記住的關係

σ 小 → 觀測較精密 → p 大 → 對結果影響較大

σ 大 → 觀測較不精密 → p 小 → 對結果影響較小
普通最小二乘：AᵀA x̂ = AᵀL

加權最小二乘：AᵀPA x̂ = AᵀPL
